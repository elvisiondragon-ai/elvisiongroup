  2. iOS PWA-Only Performance Optimization

  File: src/contexts/AuthContext.tsx

  Detection Logic:
  // Check if running as iOS PWA
  const isIOSPWA = window.navigator.standalone === true &&
  /iPad|iPhone|iPod/.test(navigator.userAgent);

  Fast-Track Auth Implementation:
  const initializeAuth = async () => {
    try {
      const { data: { session } } = await supabase.auth.getSession();
      setUser(session?.user ?? null);
      setUserId(session?.user?.id ?? null);
      setLoading(false); // Immediate auth screen access

      if (session?.user) {
        if (isIOSPWA) {
          // Defer operations only for iOS PWA
          setTimeout(() => {
            checkProStatus(session.user.id, true);
          }, 100);

          setTimeout(() => {
            rebuildChatChannel(session, 'deferred setup');
          }, 500);
        } else {
          // Normal browser - immediate execution
          checkProStatus(session.user.id, true);
          rebuildChatChannel(session, 'immediate setup');
        }
      }
    } catch (error) {
      console.error('Initial session check failed:', error);
      setLoading(false);
    }
  };

  3. Platform-Specific Delay Configuration

  iOS PWA Delays:
  - Pro status check: 100ms delay
  - WebSocket channel setup: 500ms delay
  - Idle user handlers: 100ms delay
  - Recovery logic: 200ms delay

  All Other Platforms (No Delays):
  - Desktop browsers (Chrome, Firefox, Safari, Edge)
  - Android browsers
  - Mobile Safari (non-PWA)
  - All other platforms: 0ms delay (immediate execution)

  Implementation:
  // Move heavy operations to background only for iOS PWA
  const setupDelay = isIOSPWA ? 100 : 0;
  const recoveryDelay = isIOSPWA ? 200 : 0;

  setTimeout(() => {
    // Heavy operations here
  }, setupDelay);

  How It Works

  Step-by-Step Process:

  1. Browser Opens
    - HTML splash screen shows instantly
    - User sees icon + spinner immediately
  2. JavaScript Loads
    - Platform detection runs
    - Auth initialization starts immediately
  3. iOS PWA Path:
    - Session check: immediate
    - Auth screen: immediate access
    - Heavy operations: delayed in background
  4. Other Platforms Path:
    - Session check: immediate
    - Auth screen: immediate access
    - All operations: immediate (no delays)
