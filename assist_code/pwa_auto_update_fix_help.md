To address the issue of the production app not updating, a new component `ServiceWorkerUpdater.tsx` has been created and integrated into `App.tsx`. This component uses the `useRegisterSW` hook from `vite-plugin-pwa` to automatically detect when a new service worker is available and forces an update. This ensures that users will always have the latest version of the application without needing to manually clear their cache or unregister the service worker.
