# Pixels Tool Help

This tool is designed to monitor Meta Pixel and CAPI events sent to the eL Vision Group database.

## Filtered Events
To keep the logs clean and focused on conversions, only the following events are captured and displayed:
- **Purchase**: Successful payment confirmation.
- **Test_Purchase**: Payment confirmation in test mode.
- **AddToCart**: User added a product to their cart/initiated a buy action.
- **AddPaymentInfo**: User provided contact/billing details.

## Features
- **Real-time Updates**: New events will appear automatically as they are triggered.
- **Search**: Search by email, reference ID, or event name.
- **Mobile Responsive**: Optimized for viewing on both desktop and mobile devices.
- **Infinite Scroll**: Scroll down to load older events.

## Pixel Names
The tool maps Pixel IDs to human-readable names:
- `1393383179182528` -> USA KAYA PIXEL
- `1797660474333865` -> Fit Factor PIXEL
- `3319324491540889` -> GENESIS200 PIXEL
